# 知识库本地工具

本目录保存随知识库部署的固定工具，当前 `deploy/` 负责运行依赖准备、能力分发及已部署能力登记。它不属于 Skill 包，不作为原件或正式知识采集；`knowledge/` 继续只存知识卡。部署工具不得从业务原件加载程序。

环境准备读取本目录的运行锁，不要求项目根存在 `skills/` 或 `workflows/`。登记 Agent 最终目录时只读能力，以实际位置生成 catalog/registry；不自动修改宿主注册、不移动能力目录、不在安装中执行 Git 操作。保留精确版本、内容摘要、防链接、新目录和失败不发布边界。运行锁与源码能力的运行锁应保持一致。

测试在 `deploy/tests/`，使用隔离材料和新目标目录；不读受限 gold，不覆盖已有环境，不将本机登记产物写进共享配置。目录变更同步共享说明；本项目 SDD 与验证原始记录仅本地维护。
