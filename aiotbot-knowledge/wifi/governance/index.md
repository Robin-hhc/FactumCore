# 治理导航

| 位置 | 职责 |
|---|---|
| `framework.lock.yaml` | 固定现有声明契约摘要 |
| `sources.lock.yaml` | 来源资源和快照登记，当前为空 |
| `schemas/` | 字段形状、Profile 与公共受控值 |
| `contracts/` | 领域契约适配；当前缺外层执行程序，不能独立运行 |
| `templates/` | 七类卡、导航与人工确认模板 |
| `specs/` | 卡片、来源、记录和生命周期规范 |

目标文件、开发要求与验收见[详细设计](../docs-llm-wiki/知识库详细设计.md)；实际部署以[布局记录](../docs-llm-wiki/sdd/knowledge-v1/records/workspace-layout-20261020.md)为准。
