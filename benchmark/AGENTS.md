# 评测管理材料

继承仓根规则。各实验子目录保存协议允许的输入、用例定义和评测管理资料；普通研究、问答或知识生产不能读取 `gold/` 内容。

| 材料 | 用途 |
|---|---|
| `README.md`、协议及问题模板 | 了解评测目标、输入限制和执行方法 |
| `cases.yaml`、`pilot-cases.txt` 等 | 依任务和协议使用的题目/基线定义；不自动代表正式成绩 |
| `gold/`、判分锚点及历史答案 | 仅明确授权的评测管理或评分审阅使用；不得喂给被测 Agent 或建库 |
| 实际运行输出 | 按协议独立记录并核对基线；本目录存在不证明已运行或已判分 |

进入某次评测先核对其协议。管理权限与被测执行权限分开，gold 不进入源码/来源/知识索引输入；目录、AGENTS 和索引排除都不替代外部 harness 的文件及工具隔离。组内题目、答案和运行输出沿用组权限，不自动共享。

没有评测审阅授权时止于允许的入口，不批量展开 gold。保持原始材料身份，合成工具回归与真实业务评测分别报告。
