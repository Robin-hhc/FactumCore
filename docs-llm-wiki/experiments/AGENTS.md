# 评测协议与运行记录

继承仓根及 docs 规则。本目录保存研究实验的协议、环境、配置说明和实测报告；可公开用例与受限评分材料分别按 benchmark 协议管理。

- 未运行的方案标为协议/计划；运行后才记录实际版本、输入、模型、预算、日志位置、结果及限制，不预填成功成绩。
- 比较方案时固定题目、来源/代码基线、提示词、模型与预算，分别报告证据质量、严重错误和成本。
- 被测 Agent 和建库输入不得读取 gold、评分规则中的答案事实、历史答案或此前方案输出。文件/工具隔离由实际 harness 落实，本文规则不是执行隔离。
- 业务材料、题目、运行日志及派生产物按组授权处理；不把内网结果或原始日志自动发到公共远端。
- 试验结论作为有条件的研究证据；改总体决策时进入设计主稿，不直接宣称所有产品已验证。

交付区分“协议准备、实际执行、评分、结论”，能定位真实运行依据；低影响说明修改不触发重新运行业务评测。
