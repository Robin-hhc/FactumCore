# 研究工程规格与计划

继承仓根及 docs 规则。这里的 `specs/` 保存本研究工程的需求、方案和验收定义，`plans/` 保存相应执行计划；不是量产组件的规格/设计/任务真源。

- 先读同主题 spec 再调整 plan；计划注明依赖、待确认输入、阶段动作和完成条件，未执行步骤不写成已交付。
- 规格或计划变更需核对当前主设计和知识仓真实接口；历史 raw0/raw1、工具参数和自动化承诺不自动有效。
- 真实业务 SDD 原件留所属业务工程；研究工件的可复用结论要另走知识摄入及真实复核。
- 保留既有历史工件的当时身份，纠错和新决策另作明确说明，不伪造执行记录或覆盖别人的未提交计划。

交付说明哪些需求已实现、哪些待部署/验证，以及实际检查证据；不以任务清单勾选替代工程或语义验收。
