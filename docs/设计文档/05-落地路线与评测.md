## 2. 评测升级（按需，吃 w5 评测集补消费侧指标）

> 评测征集难产后不设数量门槛：现有题（评测集出题表，含黄瀚成 3 题真实样例）先跑起来，随使用逐步补；评测主要服务于健康度看护与验收，不再是选型门槛。

在 w5 关键点评分（key_facts / nice_facts / forbidden_claims）基础上增加：

- **检索质量维度**：top1 命中率、召回、排序质量（对固定问题集，人工标注相关页）；
- **拒答检验**：信息不足应拒答 / 信息充分不误拒（评测集新增拒答题）；
- **消费侧对照指标**：耗时 / 回合数 / 工具调用 / Token/条 + 内容重合率（对照组：grep+读原文 vs 知识库检索），对齐 cannbot API 检索评测口径；
- **结果回流**：问答产出回填到对应 concept/entity 卡，形成知识复利；数据看板持续呈现。
