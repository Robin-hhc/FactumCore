# 总体设计与历史细化稿

先读 [README.md](README.md)，再读 [Wi-Fi 知识库架构设计.md](Wi-Fi%20知识库架构设计.md)。本目录保存知识系统架构，不是业务组件 SDD 原件目录。

- 主稿描述 workspace、边界、治理/消费及阶段交付；用户更新的事实和约束优先按其证据核对，不能用旧稿覆盖。
- 01–05 是状态入口标注的历史细化稿；旧 raw0/raw1、字段、路径及工具承诺不能直接作为现行实现接口。
- 知识 Schema/Contract 的具体规则在独立知识仓 `governance/`；实现与设计不符时分别指出，不在本目录另建重复可执行契约。
- 组权限架构、无 Git 代码导出等新增约束，分别说明现有条件、建议控制及待验证项。目录约定不等于 ACL，外部 revision 不等于本机 HEAD。
- 新决策写入主稿或有清楚身份的补充，不用新增同名总设计制造真源冲突。主稿修改后再核对知识仓副本，不能假定自动一致。

交付核对职责、当前/目标状态、相对链接和待定项；不要为了修正文档引用静默导入内网事实或改变历史运行成绩。
