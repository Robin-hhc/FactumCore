# WiFi 知识正文

本目录只保存经对应治理路径正式落位的知识卡。先读 [AGENTS.md](AGENTS.md) 确认使用和修改边界，再按问题进入类型导航。导航页不是知识结论，不参与正文检索评分。

| 类型 | 内容与边界 |
|---|---|
| [实体](concepts/entities/index.md) | 职责、边界、接口和依赖 |
| [流程](concepts/flows/index.md) | 有条件的步骤与调用/消息；完整链路和片段分开 |
| [协议](concepts/protocols/index.md) | 标准机制及产品支持边界 |
| [规则](rules/index.md) | 对象、约束、例外和批准身份 |
| [命令](commands/index.md) | 环境、语法、输出判读和验证状态 |
| [排查手册](runbooks/index.md) | 条件分支、根因状态、恢复和验证 |
| [术语](glossaries/index.md) | 定义、别名、歧义和语境 |

模板、合成验收数据和 raw 原件不因为出现在仓内就成为 stable 知识。正式内容见各类型导航，入库与检索状态按正式处理记录和实际索引核对。
