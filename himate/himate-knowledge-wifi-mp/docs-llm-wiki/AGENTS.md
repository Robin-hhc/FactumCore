# HiMate 文档维护路由

用户操作统一维护在[使用说明](使用说明.md)，涵盖安装、放文档、OpenFlow 入库、查询与后续维护。正式知识在 `../knowledge/`，Skill 与 Workflow 源码分别在 `../skills/`、`../workflows/`。

| 任务 | 先读 |
|---|---|
| 用户安装与日常使用 | [使用说明](使用说明.md) |
| 组件、目录与数据归属 | [架构设计§5.3](HiMate知识库架构设计.md#53-himate-knowledge目录架构) |
| P1—P5、六决策和巡检 | [详细设计](知识库详细设计.md) |
| 开发与验证 | [开发指南](../CONTRIBUTING.md)和[测试入口](../evals/README.md) |

用户文档保留完成任务所需的信息。CLI 契约与节点材料放在对应 Skill 的 references；本地运维、试运行和迁移笔记保留在被 Git 忽略的开发工件中，不作为共享链接目标。

按当前源码和 Workflow 核对设计。Skill 写单步目标、操作和交付，Workflow 维护角色、顺序与出口。目录图、流程图、示例和跨文档锚点随对应行为一同更新。
