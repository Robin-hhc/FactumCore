# HiMate 文档维护路由

本目录面向知识库使用者，描述当前原理、职责和操作。正式知识在 `../knowledge/`，Skill 与 Workflow 源码分别在 `../skills/`、`../workflows/`。共享示例用 `repo/` 表示 manifest 工作区根，知识根由项目根实际 `config.yml` 选择；manifest 根不要求自身为 Git 仓。

|---|---|

目录与数据归属在架构设计维护，流程和节点交接在详细设计维护，普通用户操作在使用说明维护；环境配置、可执行参数和手动命令在运维与命令参考维护。README 与本文件提供路由；文档之间用链接衔接。

按当前源码和 Workflow 核对设计，说明真实支持的格式、参数、路径和继续方式。正文采用客观的当前行为描述，开发过程、试运行成绩和迁移记录保留在本地开发工件。

Skill 写单步目标、操作和交付，情境细节放必要 references；Workflow 维护角色、顺序与出口。目录图、流程图、参数示例及跨文档锚点随对应行为一同更新。
