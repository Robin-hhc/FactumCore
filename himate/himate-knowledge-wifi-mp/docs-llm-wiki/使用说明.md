# HiMate 知识库使用说明

使用流程：安装一次，把文档放入知识库，在 OpenFlow 入库，再使用query skill直接提问。

## 首次安装

把完整知识包放到业务工作区的 `himate/himate-knowledge-wifi-mp/`，准备 Python 3.10—3.12 和 OpenFlow，并确认执行机器的 pip 镜像可用。文档和代码在服务器时，在服务器部署，由 OpenFlow 已配置的 SSH 能力执行后续任务。

进入知识根，按系统运行：

| 系统 | 安装命令 |
|---|---|
| Linux | `sh ./deploy.sh` |
| Windows PowerShell | `.\deploy.ps1` |

需要指定解释器时，Linux 加 `--python '<Python路径>'`，Windows 加 `-Python '<Python路径>'`。依赖或模型准备失败时，安装停止并保留原有能力包；解决提示的问题后重新安装。

## 放入文档

将原件放进当前知识根的 `docs-raw/`，例如：

```text
himate/himate-knowledge-wifi-mp/docs-raw/specs/radio-design.md
```

支持 MD/TXT、PDF、DOCX、XLSX、PPTX、HTML、CSV 和常见图片；旧版 `.doc` 先转换。扫描件可使用已安装的 OCR，图示仍由 Agent 核读。`AGENTS.md`、`README.md`、`index.md` 是说明或导航，不参与自动扫描。

## 在 OpenFlow 入库

打开实际业务工作区，运行 **“WiFi 知识入库”**（`hs-knowledge-ingest`）。

Agent 会阅读材料、规划和编写知识卡，经独立审阅后入库。每轮处理一个变化文件；多份文档可继续运行，或使用后面的巡检工作流逐份处理。放入目录后需要启动工作流，目录没有后台监听。

以工作流实际返回结果确认完成。依据不足时，Agent 会说明缺口；中途失败时保留现场，让 Agent 沿当前任务继续。

## 查询

安装了该 Skill 且能访问知识库的 Agent 均可查询，不限于 OpenFlow。

提出问题并指定 `hs-knowledge-query`，例如：

> 使用 hs-knowledge-query 帮我查一下 LLC 封装的帧格式。

Agent 会检索并精读正式知识卡，按需核对原文和代码，回答时附来源及适用条件。无需手工运行搜索命令。

## 后续维护

- **文档更新或删除**：修改或移除原文件后，再运行同一个入库工作流。
- **批量检查变更**：运行 **“WiFi 知识治理巡检”**（`hs-knowledge-lint`），逐份处理文档和已引用代码的变更，并汇总待办。
- **同时使用**：查询可与入库共存；同一知识根的入库和巡检串行运行。
- **升级或换机**：保留原件、正式卡、来源登记及实际项目配置，携带模型包，在新机器重新安装。
