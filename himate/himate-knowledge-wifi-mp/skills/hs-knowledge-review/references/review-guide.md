# 内容复核

检查本轮是否读懂来源：关键结论、数值、行为、适用条件是否正确；有没有漏掉值得沉淀的新主题；已有关联卡中哪些确实不受影响。

检查改稿是否合理：相同主题是否融合、是否丢掉仍有效的内容和其它来源、是否重复新建卡；merge/split/deprecate 是否交代旧结论和链接去向。

检查结论与依据是否对应：设计要求保持设计属性，实现事实需要实际代码，测量结论需要实际测量证据；代码引用本身不证明实现。版本或条件冲突明确说明，缺依据不得推断。

正常更新旧卡时，对照原声明核对 scope、各结论条件、历史依据和验证要求已迁入相应正文，保留有效定位、锚点和链接。局部过时不整卡退役；普通更新保留原生命周期，恢复退役卡须有 P2 决定。

报告具体卡、结论和依据。决定错回 P2；决定正确但稿件错回 P3。空候选也要检查范围内遗漏的新主题：PDF 以实际 `source_pages` 为完整评估范围，宽候选未选部分留待续办；非 PDF 以整份来源为范围，不能仅复核作者选中的主题后就登记完成。

PDF 目录、空白和参考页须核实后才能判定无增量；没有提取文字不等于已确认空白。卡片 doc_ref 只表达结论证据，不能反推该页已完整评估；必要跨章补读也不自动增加覆盖。页段覆盖只证明处理范围已登记，不证明 Agent 读懂，内容判断仍由独立 reviewer 承担。

PDF 缺口摘要保留次数和完整明细入口，partial 仍是 partial；摘要或 image_count=0 不表示图示已被提取或理解。实际 source_pages 内的图示须打开原 PDF 或页预览核对，缺必要图意时不能通过；候选外未选页的图元留待续办，不要求本批先解决全书提取缺口。
