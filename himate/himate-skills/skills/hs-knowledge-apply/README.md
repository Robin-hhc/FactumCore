# hs-knowledge-apply（发布本批知识）

## 中文介绍

这是知识入库的 P5 阶段。它把通过 P4 审阅的候选卡写入正式库，执行审阅确认的删除，并更新引用关系、检索索引和本批处理记录。通过命令回执可以看到本批实际发布了什么，以及还有哪些范围需要继续处理。

## 使用方式

> 这批候选已通过 P4。请用 hs-knowledge-apply 发布本批，告诉我哪些卡发生了变化、实际处理了哪些来源、接下来还剩什么。

## 限制与边界

- 发布范围以 P1 选中的文档和 P4 已审材料为准。分批文档只登记本批实际评估单元，剩余范围另批续办。
- 本批失败时保留已审稿和暂存现场。若写入状态不明，先用同一已审稿重试或报告失败。
- 引用的 evidence_version 由程序按本轮实际核验输入保存；源码变动需重新核对，不由 Agent 手工替换标签继续发布。
- 正式库发布与 Git 提交是两个动作。Git 提交、推送与合入需单独授权。
