# hs-knowledge-capture（整理知识原稿）

将选定讨论中的技术结论，或指定源码流程整理成可独立阅读、可回查的原稿。会话总结和源码分析分别读取专注参考，共享证据归因与原稿骨架。

OpenFlow 的“总结会话”在当前会话发起整理；知识库页“源码自分析”新开分析会话，带入绑定库、实际执行端和用户问题。Agent 读取原文或源码，在普通会话给出草稿；用户可继续要求修改，确认质量后再保存。确认前不创建知识库原件。

Agent 用普通文件工具将确认稿及真实配图保存到绑定库的 `docs-raw/agent-notes/`，并返回可打开的实际路径。有本地配图时沿用知识库已有资料包格式，用户不必自行整理附件。

保存后建议将当前会话绑定到 `hs-knowledge-ingest`。OpenFlow 已有建议卡时，用户点击进入既有入库流程；没有这一能力时只给操作提示。交接范围为本次原稿，不泛扫整个库，不自动替换当前会话已有的 Workflow。保存原件不等于生成正式卡片。

也可直接请求：

> 请用 hs-knowledge-capture 整理本轮最终确认的重试条件、测试依据与未知范围，先给我审阅。

源码依据保留实际版本与位置，未知宏和运行表现不写成已验证事实。无法读取或保存时报告实际缺口，不虚构文件或 Workflow 已启动。
