# hs-knowledge-capture（沉淀组库分析稿）

## 中文介绍

将一轮讨论中的技术结论写成可独立阅读的组库文档，也可从指定的函数入口出发整理源码分析。稿件会写明结论适用的条件、实际使用的证据和仍待核实的范围，便于后续按主题入库。

## 使用方式

> 请用 hs-knowledge-capture 把本轮确认的重试条件、对应测试和未验证的场景整理成一份组库分析稿。

做函数分析时，可以同时给出模块、文件路径或调用位置，便于区分同名入口。稿件默认落在已确认知识根的 `docs-raw/agent-notes/`，交付时会给出实际文件路径。

## 限制与边界

- 适用条件和结论引用实际证据。未知构建条件、宏开关及运行表现保留为未核实。
- 已有同名材料时使用其他文件名。当前完成状态为「已落盘，发布接口未接入」，正式归卡由后续入库流程处理。
