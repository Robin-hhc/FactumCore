# 会话原稿

按用户选定范围整理；未另选范围时，以发起总结前的本轮讨论为准。已有摘要不足以核实关键条件时，读取相关原消息和实际证据。用户后来补充的信息按其意图用于本稿修改，不无关扩展。

识别最终决定与被撤销的设想，按讨论中的实际归因表述。设计约束不写成实测结果，单个测试记录不外推到未覆盖的并发、环境或失败条件。删除寒暄和重复推演，保留会改变后续使用结论的例外。

来源保留实际可取得的会话名称、消息身份和证据位置，不编造 ID。重要短文本证据可在稿内摘录并标明原身份；没读到的原文不能补写成证据。不要把临时工作区相对路径当成保存后仍可打开的引用。配图使用真实可取得的文件，缺失时指出具体缺口。

在同一会话根据用户反馈修稿，保留仍成立的条件与证据。确认后保存用户审阅的稿件，不另行生成另一份结论。
