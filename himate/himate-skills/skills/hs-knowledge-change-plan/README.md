# hs-knowledge-change-plan（制定知识编辑计划）

## 中文介绍

在知识入库的第二步（P2），读完本批材料覆盖的范围并核对关联旧卡，判断应更新、合并、拆分、退役、暂缓或新建哪些卡。计划写给后续作者，说明要改的知识、依据和需要保留的条件。

## 使用方式

对 Agent 说：“请用 hs-knowledge-change-plan 读这一批来源和关联卡，把编辑计划写进 `.build/plan.md`。同主题的旧卡优先沿用原有 ID 和路径。”

## 输入与输出

- 输入为来源准备结果 `.build/task.json`、本轮材料及关联旧卡。
- 输出为 `.build/plan.md`，其中列出待成稿的卡 ID 和正式路径。现存原始 PDF 还要声明本批实际评估的物理页段。

## 限制与边界

- 本步交付短计划，完整候选卡由 P3 撰写。
- PDF 计划的起点与任务一致，结束页以实际完整评估范围为准。需要关键依据时先说明缺口，并把受影响的处理暂缓。
