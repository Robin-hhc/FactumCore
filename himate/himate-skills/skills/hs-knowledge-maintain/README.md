# hs-knowledge-maintain（审计正式知识的来源引用）

## 中文介绍

独立检查正式卡引用的已登记来源是否仍可定位，列出缺失或无法访问的来源和相关卡片。这适合在搬迁资料或排查失效引用时做一次审计。

## 使用方式

> 请用 hs-knowledge-maintain 检查这个库的正式卡引用，列出找不到的原件、关联卡和对应错误。

Agent 会用已确认的工具入口和知识根执行 `maintain audit`，再根据本次返回的诊断整理报告。

## 限制与边界

- 本 Skill 交付审计报告。来源修复和正式卡更新交给相应的入库流程，周期同步及变更处理由巡检流程负责。
- 审计结果仅覆盖正式卡已引用的登记来源。空结果不能据此判断所有原始资料都已被处理。
