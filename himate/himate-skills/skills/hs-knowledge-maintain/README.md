# hs-knowledge-maintain（审计来源路径与文件存在性）

## 中文介绍

独立检查正式卡已引用的登记来源路径能否解析、对应文件是否存在，列出缺失文件或路径解析失败的来源和已知关联卡。这适合在搬迁资料或排查缺失原件时做一次审计。

## 使用方式

> 请用 hs-knowledge-maintain 检查这个库的正式卡引用，列出找不到的原件、关联卡和对应错误。

Agent 会用已确认的执行端和知识根执行 `maintain audit`，再根据本次返回的诊断整理报告。普通会话未提供审计 MCP 工具时直接使用 CLI；实际提供 `knowledge_maintain_audit` 时沿用其绑定。

## 限制与边界

- 本 Skill 交付审计报告。来源修复和正式卡更新交给相应的入库流程，周期同步及变更处理由巡检流程负责。
- 审计结果仅覆盖正式卡已引用登记来源的路径解析和文件存在性。它不验证文件内容可读取、代码符号或行号、正文证据及卡片结论；空结果也不能说明未被引用的原件已入库。
