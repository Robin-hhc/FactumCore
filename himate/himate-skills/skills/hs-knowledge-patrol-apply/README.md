# hs-knowledge-patrol-apply（发布关联卡维护结果）

## 中文介绍

巡检的 L6 发布程序校验的定位修复，或通过独立 L5 的语义维护批次，更新索引并记录实际引用处理结果。

## 使用方式

对 Agent 说：“请用 hs-knowledge-patrol-apply 按本批任务模式发布维护结果，并报告实际回执。”

## 输入与输出

- 输入为固定任务及候选。机械任务具有同批程序检查入口；语义任务已独立审阅，零正文改动时包含实际理由。
- 输出为实际改卡、已处理引用及维护完成状态，区分程序定位修复和内容审阅。

## 限制与边界

失败保留原批次重试。机械凭据不能由模型手写，也不能冒充 L5 内容通过。引用处理完成不表示整份代码被入库。
