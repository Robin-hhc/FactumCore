# hs-knowledge-patrol-complete（汇总巡检结果）

## 中文介绍

知识治理巡检的最后一步（L8）。它统计当前仍待处理的来源，并结合本轮各步骤的回执汇总已处理文件、暂缓原因和实际错误，方便使用者确认本轮进度。

## 触发场景

- “索引刷好了，给我一份这轮巡检的汇总。”
- “这份 PDF 只处理了部分页面，帮我区分已做和尚未完成的事。”

## 使用方式

对 Agent 说：“用 hs-knowledge-patrol-complete 汇总已绑定库这轮巡检。按实际发布回执列出处理结果，再报剩余来源和已知原因。”

## 输入与输出

输入为已确认的知识库和本轮处理回执。统计命令返回 `completed` 和 `data.remaining`，并将最新统计写入知识库中的 `artifacts/patrol/latest.json`。处理过的文件及其已知错误由相应步骤回执提供。

## 限制与边界

`completed` 表示本轮统计结束，仍需查看剩余数量。来源处理状态由各次 P5 或 L6 登记，本步负责统计。
