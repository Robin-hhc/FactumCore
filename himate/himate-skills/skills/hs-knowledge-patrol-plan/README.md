# hs-knowledge-patrol-plan（选择巡检待办）

## 中文介绍

知识治理巡检的第二步（L2）。它比较当前原件、正式卡引用的已登记代码文件与各自上次成功处理的版本，选出一份待处理来源。内容没有待办时，它判断索引是否需要重建。

## 触发场景

- “同步完了，先找一份这轮要处理的来源。”
- “这轮只有索引过期吗？帮我确认一下。”

## 使用方式

对 Agent 说：“用 hs-knowledge-patrol-plan 查一下已绑定库的下一项治理待办，给我来源 ID 和后续应该走的步骤。”

## 输入与输出

输入为已确认的知识库及其中的原件、来源登记和正式卡。结果是 `needs_ingest`（将真实的来源 ID、类型和路径交给 P1）、`needs_reindex`（交给 L3）或 `unchanged`（交给 L4 汇总）。

## 限制与边界

这一步止于选出一份待办或判断索引状态。材料暂存由 P1 负责。代码范围限于已登记且被正式卡引用的文件。
