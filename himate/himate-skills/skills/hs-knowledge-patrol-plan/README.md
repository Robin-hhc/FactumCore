# hs-knowledge-patrol-plan（选择并分流巡检待办）

## 中文介绍

巡检的 L2 根据实际原件、来源登记和正式引用选择一项待办。文档新增、变更或未完成进入 P 链，已有卡及引用维护进入 L3–L6，无内容待办时判断索引。

## 使用方式

对 Agent 说：“请用 hs-knowledge-patrol-plan 检查本轮下一项待办，保留真实来源和变化类型，按回执分流。”

## 输入与输出

- 输入为已确认的知识根、原件、来源登记和正式卡。
- 输出为 needs_ingest、needs_maintenance、needs_reindex 或 unchanged，以及实际选定来源。

## 限制与边界

本步止于分流。代码仅覆盖已登记且被正式卡直接引用的文件，引用缺版本进入已有卡复核，未引用代码不自动入库。不因整文件其他内容变化自行扩大维护范围；机械/语义任务采用 L3 的实际程序分类。
