# hs-knowledge-patrol-prepare（准备已有卡维护材料）

## 中文介绍

巡检的 L3 根据 L2 选定的来源准备固定维护任务。程序按引用版本观察确定卡片及引用范围，材料包含实际状态、相关来源、原卡和可用历史证据。

## 使用方式

对 Agent 说：“请用 hs-knowledge-patrol-prepare 为 L2 选中的 code-wait 准备关联卡维护材料。”

## 输入与输出

- 输入为L2 的来源 ID、变化类型，以及已确认的知识根和执行端。
- 输出为 mechanical_prepared 定位修复任务（交 L6）、prepared 语义任务（交 L4），或该来源暂无待办、具体备料缺口。

## 限制与边界

不修改正式卡，不扩展为全文代码入库。程序定位修复采用同批机械凭据；缺引用版本仍需复核，不能自行改为机械通过。
