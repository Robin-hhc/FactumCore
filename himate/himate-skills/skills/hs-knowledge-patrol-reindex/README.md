# hs-knowledge-patrol-reindex（刷新巡检索引）

## 中文介绍

知识治理巡检的第三步（L3）。正式卡和来源登记已就绪时，更新库中的关系和检索索引。首次生成完整索引，后续按变化增量更新。

## 触发场景

- “L2 说没有内容待办，帮我刷新一次索引。”
- “正式卡已更新，检索或引用关系还没反映出来。”

## 使用方式

对 Agent 说：“用 hs-knowledge-patrol-reindex 根据已绑定库的正式卡和来源登记刷新索引，完成后交给 L4。告诉我工具返回的结果。”

## 输入与输出

输入为已确认的知识根、正式卡和来源登记。刷新成功时返回 `reindexed`，后续由 L4 汇总巡检结果。

## 限制与边界

刷新更新数据库关系与检索索引。原件、知识正文以及各来源的成功处理版本来自正式资料。刷新失败时报告具体诊断。
