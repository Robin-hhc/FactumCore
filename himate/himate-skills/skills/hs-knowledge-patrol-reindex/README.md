# hs-knowledge-patrol-reindex（重建巡检索引）

## 中文介绍

知识治理巡检的第三步（L3）。正式卡和来源登记已就绪、索引需要刷新时，它重建库中的关系和检索索引。适合处理正式卡已经存在、检索结果还没更新的情况。

## 触发场景

- “L2 说没有内容待办，帮我重建一次索引。”
- “正式卡已更新，检索或引用关系还没反映出来。”

## 使用方式

对 Agent 说：“用 hs-knowledge-patrol-reindex 根据已绑定库的正式卡和来源登记重建索引，完成后交给 L4。告诉我工具返回的结果。”

## 输入与输出

输入为已确认的知识根、正式卡和来源登记。重建成功时返回 `reindexed`，后续由 L4 汇总巡检结果。

## 限制与边界

重建只更新数据库关系与检索索引。原件、知识正文以及各来源的成功处理版本保留原值。重建失败时报告具体诊断。
