# hs-knowledge-patrol-review（独立审阅关联卡维护）

## 中文介绍

巡检的 L5 对语义任务先运行固定维护检查，再独立核对原卡、候选、逐卡决定和实际引用证据。零正文改动仍需实质复核；程序机械任务不在此制造内容通过。

## 使用方式

对 Agent 说：“请以独立 reviewer 使用 hs-knowledge-patrol-review 审阅本批维护结果。”

## 输入与输出

- 输入为固定任务、原卡、维护决定、候选和实际证据。
- 输出为review.md 中的通过依据，或具体返工问题及未完成事项。

## 限制与边界

不根据机器检查通过或空候选直接批准，不创建新主题卡片。
