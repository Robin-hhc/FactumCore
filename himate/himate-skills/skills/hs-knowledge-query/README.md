# hs-knowledge-query（检索知识卡并核对来源）

## 中文介绍

按关键词和可选标签找正式知识卡，阅读完整正文，再沿引用核对依据。适用于需要回答技术问题、比较版本差异或确认某条结论适用范围的场景。答复会给出相关卡 ID、来源和仍缺的证据。

## 使用方式

> 请用 hs-knowledge-query 查「扫描重试」，只看带 wifi 标签的卡片。读完相关卡并核对引用后，告诉我哪些结论适用于当前版本。

支持的检索参数、读卡及回源格式见[公开 API](references/public-api.md)。

## 限制与边界

- 检索命中只表示与关键词相关。适用性要结合卡片正文、版本、条件和实际证据判断。
- 空结果与命令执行失败要分别判断。查询报告保存在 `artifacts/query/`，入库暂存和正式知识发布由入库流程处理。
