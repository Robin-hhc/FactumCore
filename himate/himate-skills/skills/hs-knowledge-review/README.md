# hs-knowledge-review（独立审阅候选）

## 中文介绍

在知识入库的第四步（P4），先执行固定检查，再由独立审阅者对照材料、短计划、旧卡和候选稿，复核结论、条件、引用以及遗漏。正式知识库的只读引用审计由 hs-knowledge-maintain 提供。

## 使用方式

对 Agent 说：“请用 hs-knowledge-review 独立审阅这批候选，把判定、范围和需要返工的地方写进 `.build/review.md`。”

## 输入与输出

- 输入为本轮任务、编辑计划、固定版本的来源材料、旧卡及完整候选。
- 输出为审阅记录，写明通过或返工的依据、实际审阅的范围和未能核实的材料。独立检查正式库时，返回工具的检查结果。

## 限制与边界

- 固定检查通过后，仍要补足独立内容核对。候选内有必要的材料未审时，发布交接暂停。
- 实质决策、事实、适用条件或归卡有问题时回 P2。格式、引用填写或组稿有问题时回 P3。
