# hs-knowledge-source（准备入库来源）

## 中文介绍

在知识入库的第一步（P1），按选定文档范围检查原始资料，也可处理巡检交接的文档待办。每批为一份文档整理同版原件、已有引用卡、图片和阅读材料。长文从最早未评估单元续办，已有卡的代码维护由巡检 L3–L6 处理。

## 使用方式

对 Agent 说：“请用 hs-knowledge-source 扫描 `docs-raw/specs`，准备下一份待入库材料。”如需续办一份 PDF，可说：“请用 hs-knowledge-source 继续准备 `docs-raw/specs/radio.pdf` 中还没评估的页面。”

## 输入与输出

- 输入为已确认的知识根及本轮入库范围，或巡检交接的来源 ID。独立使用时先核对执行端的工具入口和知识根。
- 找到待办时，交接本批文档任务、原件副本及关联卡。分批文档另附候选单元、索引和阅读入口。

## 限制与边界

- 每次只准备一份来源，扫描范围沿用本次开始时的选择。
- 文档候选单元供后续选择实际评估区间。成功处理的范围由独立审阅并发布后登记。
