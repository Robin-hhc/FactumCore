# hs-knowledge-view-materialize（撰写完整候选卡）

## 中文介绍

在知识入库的第三步（P3），根据编辑计划、本轮材料和必要的旧卡，撰写可以独立阅读和复核的完整候选卡。候选稿保留有效的旧条件及证据，在正文写清本次变化和适用范围。

## 使用方式

对 Agent 说：“请用 hs-knowledge-view-materialize 按 `.build/plan.md` 写完整候选卡。核对段落对应的依据，写完交 P4。”

## 输入与输出

- 输入为 `.build/plan.md` 的卡清单、本轮材料和需要迁入的旧知识。
- 候选稿写到 `.build/cards/`，并沿用计划正式路径中 `knowledge/` 后面的部分。

## 限制与边界

- 可写范围为计划清单指定的候选；ID、正式落位或实质决定要调整时回 P2。
- 引用指向登记原件和真实位置。正式发布由审阅后的 P5 执行。
