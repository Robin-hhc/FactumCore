# 首次准备 CodeGraph

仅在首次准备项目或用户明确要求补齐图谱时使用；日常查询通过宿主实际可调用的 CodeGraph 工具读取现有索引。

1. 从根 `config.yml` 解析 `code_root` 和 `modules[].path`，按实际代码目录去重。空 `modules` 报告未登记代码仓，不扫描整个 `main/`。
2. 在源码所在端逐目录执行 `codegraph status`。复用该目录自己的有效索引；没有自身索引时运行 `codegraph init`，再核状态。不能用祖先索引代替当前目录索引。
3. 按当前 CLI 帮助处理首次交互，保留排除范围，跳过非必要的 Git hook 或额外集成。失败保留诊断；重试只补未完成目录，不强制重建。
4. 交付实际目录和新建、复用、缺失、失败结果。`.codegraph/` 为本地派生数据，不上库。

图谱只提供定位线索，不证明代码版本、宏或构建条件。卡片 `code_ref` 使用 K 的 `governance/specs/cards.md` 支持的实际符号，不写图谱内部节点ID。纯文档不强制连接代码；固定符号导航不依赖图谱初始化。
