# Writing guide

Report the actual CLI status, phase, diagnostics and returned business file references. Use the output of this invocation; do not invent a passing result. OpenFlow owns run/node/attempt tracking and transition checks.

For declared `code_ref` values, show fixed-evidence binding and actual current navigation status separately. Preserve missing/ambiguous failures and unavailable gaps, including on document-review cards. A resolved symbol is not a semantic review, unchanged source hash or successful build.
