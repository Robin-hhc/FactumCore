# Review guide

Check the actual result and relevant card/source/view/index bytes. State unresolved gaps. Workflow order, role assignment and handoff validation belong to OpenFlow. A successful business check does not prove semantic correctness, deployment or Git merge.

Separate independent explicit event/watermark writes from read-only reports and ingest pending event drafts. Do not describe this action as regular stage cleanup.

For patrol, check the original inventory union, rules/config/source binding, actual formal publication/completion, current index and remaining debt. A skipped sync means local observation only. A reported/observed change is not a repaired card; a deferred unit or cleanup_pending must not advance the successful baseline. Fixed patrol observations survive producer stage cleanup and stay local.
