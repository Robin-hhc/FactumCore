# Review guide

Check the actual result and relevant card/source/view/index bytes. State unresolved gaps. Workflow order, role assignment and handoff validation belong to OpenFlow. A successful business check does not prove semantic correctness, deployment or Git merge.

Check that the response contains the permitted card content, logical `path`, exact-generation `card_ref` and compact `source_links`, with no embedded source text, original bytes or expanded source objects. Use the declared address base to distinguish fixed evidence from current code positions. Check that current code path/locator/digest describe one navigation observation; no file digest means no current address, and ambiguous navigation supplies no locator. The external match flag compares that current file with fixed evidence and is null without `current`. State which linked materials were actually opened; links alone are not read evidence.

The internal source/Claim binding, historical locator, symbol/current-state checks and same-generation rechecks still apply. Do not treat a resolved navigation status as unchanged source bytes, an active preprocessor branch or supported product behavior. Unknown/ambiguous navigation and material gaps remain explicit; opening a link does not expand the original query's Claim or purpose qualification.

Use exact formal generation/source references after producer cleanup. Explain missing required retained evidence without discovering old private operations.
