# Writing guide

Report the actual CLI status, phase, diagnostics and returned business file references. Use the output of this invocation; do not invent a passing result. OpenFlow owns run/node/attempt tracking and transition checks.

Present the returned card text or permitted summary, logical card `path`, exact-generation `card_ref` and compact `source_links`. Resolve the card addresses from K and source addresses from their declared bases. Open the original document or code only when needed, and distinguish material actually read from links only listed. Query results do not embed recovered source content or original bytes.

For code links, report the actual `navigation_status` and same-observation current path/range/digest separately from fixed `evidence`. An unverified current file remains null; ambiguous file addresses have no locator. `current_source_matches` compares the returned current file with fixed evidence, or is null without `current`. Navigation success does not prove the Claim's current semantics; missing, ambiguous and unavailable results retain their actual diagnostics. Use CodeGraph only as an additional source-location aid. Reading a link does not expand the original query purpose or eligible Claim set.

Use exact formal generation/source references after producer cleanup. Explain missing required retained evidence without discovering old private operations.
