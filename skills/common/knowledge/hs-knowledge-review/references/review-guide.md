# 内容复核

检查本轮是否读懂来源：关键结论、数值、行为、适用条件是否正确；有没有漏掉值得沉淀的新主题；已有关联卡中哪些确实不受影响。

检查改稿是否合理：相同主题是否融合、是否丢掉仍有效的内容和其它来源、是否重复新建卡；merge/split/deprecate 是否交代旧结论和链接去向。

检查结论与依据是否对应：设计要求保持设计属性，实现事实需要实际代码，测量结论需要实际测量证据；代码引用本身不证明实现。版本或条件冲突明确说明，缺依据不得推断。

正常更新旧卡时，对照原声明核对 scope、各结论条件、历史依据和验证要求已迁入相应正文，保留有效定位、锚点和链接。局部过时不整卡退役；普通更新保留原生命周期，恢复退役卡须有 P2 决定。

报告具体卡、结论和依据。决定错回 P2；决定正确但稿件错回 P3。空候选也要审查整份来源是否遗漏新主题，不能仅复核作者选中的主题后就登记完成。
