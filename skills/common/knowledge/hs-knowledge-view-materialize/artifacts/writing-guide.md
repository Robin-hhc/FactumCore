# Writing guide

Report the actual CLI status, phase, diagnostics and returned business file references. Use the output of this invocation; do not invent a passing result. OpenFlow owns run/node/attempt tracking and transition checks.

For run/revise, include plan_ref, view_ref, disposition_preview_ref, summary_ref, batch_kind, review_mode and the exact input_snapshot digest. A record_only batch has no content write set. A revision names the old read-only view, new operation and reason. Describe only reports an existing exact view.

For each active-card code source, identify its required `code_ref`, evidence_ref and preserved snapshot/locator binding. Do not invent code links for a pure document or substitute file/range selectors. Describe the actual saved declarations, not a passing navigation result. Do not replace old locators with current positions or add a card-level symbol registry.

Report the frozen stage-to-final mapping and exact reviewed bytes. P7 cannot rewrite references. Distinguish borrowed immutable material from this operation owned outputs.
